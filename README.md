# AI Course Notes

This repository contains beginner-friendly quick-reference notes for common data analysis and preprocessing tasks in Python.

## Contents

- **`numpy_notes.md`**  
  Practical NumPy syntax for array creation, indexing, math operations, reshaping, and common utility functions.

- **`pandas_notes.md`**  
  Core Pandas syntax for working with Series/DataFrames, file I/O, filtering, grouping, joins, and missing data handling.

- **`data_cleaning_notes.md`**  
  Step-by-step data cleaning workflow for CSV/Excel datasets, including missing values, data types, duplicates, outliers, and export.

## Purpose

Use these notes as a fast study and revision resource while learning:

- NumPy fundamentals
- Pandas fundamentals
- Real-world data cleaning workflow

## How to Use

Open any notes file and copy the examples directly into your Python environment (Jupyter Notebook, Colab, or local scripts) for practice.
